# Study of Covid-19 Cases and Pollution in Umbria

This project analyzes epidemiological data related to the spread of Covid-19 in the municipalities of Umbria and compares it with environmental, geographical, and demographic factors (PM10 pollution, population density, social deprivation index).

## Objectives

- Normalization and cleaning of the dataset
- Interactive visual analysis (Plotly, Folium)
- Clustering (K-Means) and PCA for dimensionality reduction
- Supervised regression (Linear Regression, Decision Tree)
- Interpretable modeling with pruning and cross-validation
- Construction of interactive maps for territorial insights

## Technologies

- **Python 3.13.1**
- `pandas`, `numpy`, `matplotlib`, `seaborn`, `scikit-learn`
- `plotly`, `folium`, `ipywidgets`
- `statsmodels`, `geopandas`
- Jupyter Notebook `.ipynb`
